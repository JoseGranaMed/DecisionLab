## Limitaciones y decisiones para publicación posterior

- El PDF exportado por Chrome no tiene etiquetas estructurales. La vista HTML conserva la estructura; se requiere una decisión específica si un PDF etiquetado es condición futura de publicación. No se añadió un generador PDF.
- Los 4 avisos npm restantes afectan el árbol de desarrollo de ESLint 10 mediante minimatch. Su corrección indicada por npm instala ESLint 9, un cambio de versión mayor que requeriría validar configuración y reglas; no se aplicó `npm audit fix --force`. El bundle público no contiene dependencias npm de producción vulnerables según `npm audit --omit=dev`.
- La licencia del futuro repositorio público permanece pendiente de decisión del titular en Fase 12. No se configuró remoto ni se publicó el proyecto.
- La verificación de WCAG 2.2 AA sigue siendo un objetivo; las pruebas automáticas y capturas no sustituyen una comprobación con lector de pantalla y dispositivos físicos.

**Estado 11B:** 11 hallazgos corregidos y verificados, 1 limitación aceptada y documentada, 1 hallazgo parcial con causa y alcance registrados. No se conocen regresiones que bloqueen el MVP en las pruebas ejecutadas.
